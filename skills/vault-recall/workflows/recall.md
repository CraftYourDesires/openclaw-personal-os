# Recall Patterns

## Decision recall

Query with the project name, decision subject, and approximate date. Read the meeting transcript when the decision affects ownership, money, deadlines, or external commitments.

## Person recall

Query the person's name plus the relationship or project. Separate what the person said from what Remm or another participant inferred.

## Open loop recall

Query the topic plus terms such as follow up, next step, due, waiting, and owner. Cross check TaskNotes status before calling an item open.

## Date recall

Query the date plus the likely event or project. Use daily notes for orientation, then read linked meeting or task notes for details.

## Proposed action review

Show every unchecked proposed action with its one based number. Preserve owner and due wording. Create TaskNotes files only for the numbers Remm approves.
